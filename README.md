# Pramod Ramakrishna — Personal Portfolio

A sleek, modern, high-performance personal portfolio website for **Pramod Ramakrishna**, Mechanical & Systems Engineer specializing in Model-Based Systems Engineering (MBSE), Industry 4.0, Robotics, Digital Twins, and Additive Manufacturing.

## 🚀 Features

- **Custom Domain Ready**: No Wix branding, watermarks, or third-party subdomains.
- **Light / Dark Mode**: Built-in toggle with automatic system theme detection and persistent preferences.
- **Interactive Project Showcase**: Filter projects by categories (Robotics, Additive, Automotive Racing, Systems).
- **Fullscreen Image Lightbox**: High-resolution zoomable viewer for projects, publications, and photos.
- **Academic & Industry Timeline**: Chronological presentation of experience at Robert Bosch GmbH, Otto-von-Guericke-Universität Magdeburg, Volkswagen AG, and KSCST.
- **Scientific Contributions**: Peer-reviewed publications and Master's thesis presentation.
- **Responsive & Accessible**: Optimized for mobile phones, tablets, and desktop monitors.
- **Fast & Lightweight**: Zero bloated frameworks or slow trackers; loads in milliseconds.
