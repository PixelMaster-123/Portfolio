SAP & MES Integration for Scrap Cost Detection

Master's thesis and production planning deployment at Robert Bosch GmbH developing a Model-Based Systems Engineering (MBSE) architecture that bridges enterprise ERP (SAP) with real-time Manufacturing Execution Systems (MES) to detect, isolate, and reduce manufacturing scrap costs.

1. The Industrial Data Silo Dilemma

In advanced automotive supplier operations such as Robert Bosch GmbH, sample production lines generate vast amounts of granular sensor and inspection data via shopfloor MES systems. However, financial controlling and scrap cost analysis traditionally resided in disconnected SAP enterprise databases. As a consequence, scrap cost attribution was calculated weeks after production runs, rendering preventive intervention impossible.

2. MBSE Modeling & SysML Architecture

Using Model-Based Systems Engineering (MBSE), I developed comprehensive SysML block definition diagrams (BDD), internal block diagrams (IBD), and state machine representations of the entire data pipeline. This ensured seamless semantic mapping between the mechanical workpiece lifecycle on the assembly line and the financial transaction records inside SAP CO.

3. Asset Administration Shell (AAS) Integration

By creating standardized digital twin wrappers based on the Asset Administration Shell (AAS) specification, each manufacturing station and component batch broadcasts standardized telemetry. This enables automated machine-to-enterprise cost accounting and real-time scrap anomaly alerts directly on planning dashboards.
